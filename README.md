# Discorda

A clean Discorda community-chat prototype made with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser.

## Deploy with Vercel
1. Put these files in a GitHub repository.
2. In Vercel, choose **Add New → Project**.
3. Import the GitHub repository.
4. Click **Deploy**.
5. Vercel will give you a free `*.vercel.app` address.

No database or environment variables are needed for this first prototype.
